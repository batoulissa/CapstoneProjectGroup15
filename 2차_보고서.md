# Project Summary
| Item | Content |
|:---  |---  |
| (1) Problem Definition | *Many young adults face limited access to mental health support due to language barriers, time zones, and availability—especially in South Korea where therapy is often stigmatized or inaccessible. Our target users young adults who need flexible and culturally relevant therapy options.* |
| (2) Comparison with Existing Research | *Apps like BetterHelp and Labayh offer online therapy but lack global accessibility, real-time matching, and multilingual features. TheraTalk improves on these by offering AI matching, and 24/7 chat access, making therapy more inclusive and available.* |
| (3) Proposed Solution | *TheraTalk is a mental health app powered by Google Gemini AI that connects users with therapists based on preferences, language, and availability. Key features include: -AI chatbot support -AI-matching system -Self-help modules and mood tracking -Multilingual therapists* |
| (4) Expected Impact and Significance | *TheraTalk helps normalize and improve access to therapy across borders. It offers convenient, on-demand, and inclusive mental health support, especially for young people who might not seek traditional therapy.* |
| (5) List of Core Features | *List of Core Features: 1.Language Option – Multilingual therapists 2.Appointment Booking – Book and manage therapist sessions 3.Chat-Based Therapy – Real-time secure chat (Flask + SocketIO) 4.AI Matching Algorithm – Matches based on user preferences 5.AI Chatbot – Instant 24/7 support and crisis help 6.Self-Help Modules – Helpful links, and hot-line telephone numbers 7.Mood Tracking – Daily logs, analytics, trends 8.Therapist Profiles – Info, ratings, availability * |

| (2) Overall System Architecture | *TheraTalk follows a client-server model with a mobile frontend and Flask-based backend. Frontend (React Native): Handles user interface. Backend (Flask, Python): Manages user data, chat system (via SocketIO), booking, and AI matching. Database (SQLAlchemy): Stores users, therapist data, schedules, and message history. AI Services: Google Gemini AI for chatbot. Third-party Modules: SocketIO (real-time chat)* |
| (3) Core Engine and Feature Design | *Matching Engine: Takes user input (language, therapy needs, and availability) and returns best-fit therapists using text similarity (via TF-IDF and cosine similarity). Chat Engine: Real-time communication using SocketIO with secure message logging and interface support. AI Chatbot Engine: Uses Gemini AI to provide 24/7 responses; handles basic emotional support and suggests resources based on sentiment detection.* |
| (4) Implementation of Key Features | *1. Therapist Matching Algorithm -The AI algorithm matches patients with therapists by analyzing their therapy needs, preferred languages, and availability. It calculates a personalized match score using text similarity (via TF-IDF and cosine similarity), in order to recommend the most compatible therapists. -Frontend displays profiles with filters for user refinement 2. Chat-Based Therapy -Flask + SocketIO handles real-time messaging -Messages are stored in the database -The frontend displays the chat interface.* |
